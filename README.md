# 🎯 ShooterSam

Witaj w repozytorium projektu **ShooterSam**!

## 📖 O projekcie

Ten projekt został stworzony w ramach mojej nauki i uczestnictwa w kursie **"Unreal Engine 5 C++ Game Development"**. Jego głównym celem jest poznanie i praktyczne zastosowanie fundamentów silnika Unreal Engine przy użyciu języka C++.

Repozytorium służy jako dokumentacja mojego postępu i miejsce zapisu kodu implementującego różnego rodzaju mechaniki gry (takie jak m.in. system strzelania, efekty cząsteczkowe czy proste AI oparte na Behavior Trees).

---

## ⚠️ Ważna informacja

To repozytorium zawiera **wyłącznie kod źródłowy oraz pliki konfiguracyjne**.

Wszystkie assety graficzne, modele, animacje oraz dźwięki wykorzystane w projekcie pochodzą bezpośrednio z materiałów szkoleniowych wspomnianego wyżej kursu i nie są dołączone do tego repozytorium. Z tego względu projekt nie jest gotowy do samodzielnego skompilowania i uruchomienia przez osoby trzecie, a to repozytorium pełni funkcję wyłącznie poglądową i edukacyjną.
